### 🔬 Research Overview

Research on **knowledge distillation for low-resource neural machine translation**, focusing on the Odia-to-English translation task using the Samanantar dataset.

The work investigates approaches for transferring knowledge from a teacher model to a student model, with an emphasis on translation quality and efficient knowledge transfer.

<tr>
<td width="50%" valign="top">

<td width="50%" valign="top">

#### 📚 Research Details

- **Task:** Neural Machine Translation
- **Language Pair:** Odia → English
- **Dataset:** Samanantar
- **Domain:** NLP · Knowledge Distillation · Indic Languages

</td>
</tr>
</table>

### ⚙️ Techniques Investigated

<table>
<tr>
<td width="50%" valign="top">

#### 01. Top-K Logits Distillation

A knowledge distillation approach that transfers selected high-probability teacher-model outputs to the student model.

- 🎯 Retains information from the teacher's top-K token predictions.
- 🧠 Uses selected logits or probability information for knowledge transfer.
- ⚡ Explores reducing the amount of output information used during distillation.
- 📊 Investigates the trade-off between retained information and translation performance.

</td>
<td width="50%" valign="top">

#### 02. Black-Box Knowledge Distillation

A distillation approach in which a student model learns from teacher-generated outputs without requiring access to the teacher's internal parameters.

- 🔌 Uses the teacher through its accessible input-output interface.
- 📝 Learns from generated translations or other permitted teacher outputs.
- 🧩 Supports knowledge transfer when internal model details are unavailable.
- 📈 Enables comparison with logit-based distillation approaches.

</td>
</tr>
</table>

### 🎯 Research Objectives

- Compare two knowledge distillation techniques for Odia-to-English translation.
- Investigate knowledge transfer for low-resource Indic language translation.
- Evaluate translation quality using suitable machine translation metrics, such as BLEU, where applicable.
- Study the relationship between student-model efficiency and translation performance.

<div align="center">

**Research Areas:** NLP · Neural Machine Translation · Knowledge Distillation · Indic Languages
